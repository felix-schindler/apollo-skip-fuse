First release of the fork: [`apollo-ios`](https://github.com/apollographql/apollo-ios) v2.4.0's runtime package, made to build and run on Android via [Skip Fuse](https://skip.dev/docs/modes/), with no intended behavior change on Apple platforms. Upstream v2.4.0 release notes are in the [apollo-ios changelog](https://github.com/apollographql/apollo-ios/blob/main/CHANGELOG.md#v240).

## Added

- Android support for all five targets — `ApolloAPI`, `Apollo`, `ApolloSQLite`, `ApolloWebSocket` and `ApolloTestSupport` — cross-compiled with the Swift Android SDK for `aarch64-unknown-linux-android28`.
- Non-Darwin networking path: `URLSessionDataTaskChunkLoader` (delegate callbacks → `AsyncThrowingStream`) and `AsyncHTTPResponseChunkSequence+NonDarwin` replace `URLSession.bytes(for:)`, which corelibs Foundation does not provide.
- `JSONValueConversion` (ApolloAPI `@_spi(Internal)`) to normalize the `[String: Any]`/`[Any]` values that corelibs `JSONSerialization` returns and bridges, so decoding matches Darwin.
- SQLite on Android through [`swift-toolchain-sqlite`](https://github.com/swiftlang/swift-toolchain-sqlite)'s `SwiftToolchainCSQLite` (Android/Linux/Windows); Apple platforms keep the system `SQLite3`.
- Platform-neutral test targets `ApolloAPITests`, `ApolloSQLiteTests` and `ApolloWebSocketTests`, runnable with `swift test` on macOS and `skip android test` on a device or emulator.
- CI that runs the macOS test suite plus an Android emulator build/test job, and a release workflow that publishes this changelog on tag push.

## Fixed

- Android compilation crashed (`swift-frontend` SIGABRT) for any module importing `Apollo`: `Bundle.bundleIdentifier` was redeclared on top of Android `Foundation`'s own property, making `SkipAndroidBridge`'s SIL vtable deserialization ambiguous. The helper is now gated with `#if !os(Android)`.

## Verified

From a real Skip Fuse app (Apollo client + generated models) and the platform-neutral tests, on a physical Android 12 device, an API 34 emulator, macOS and the iOS simulator:

- HTTP queries: valid and invalid auth, offline and cancellation paths, client-awareness headers, custom scalar decoding.
- WebSocket subscriptions: connect/ack, `next` decoding, ping/pong, cancellation, drop detection, and automatic reconnection after an abrupt drop (new connection, re-subscribe with the same operation id, subscriber stream stays open).
- `SQLiteNormalizedCache`: cache-first reads on Android and iOS after an app relaunch with the network off; the database file persists across force-stop/relaunch.
